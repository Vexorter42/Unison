# История изменений

## 0.2.2

- Два профиля для Happ: «Простой» (только Яндекс и ВК, без геофайлов, работает сразу) и «Полный» (все российские сайты)
- Кнопка «Отключить в Happ» — выключает маршрутизацию, если с профилем пропал интернет
- Проверка маршрутов распознаёт, когда через VPN не работает даже DNS, и подсказывает, что делать
- Окно обновления показывает описание без markdown-разметки

## 0.2.1

- Проверка маршрутов показывает, какой IP видят российские и зарубежные сайты, — сразу видно, работает ли профиль Happ
- Переключатель «Яндекс и ВК мимо VPN» больше не ломает запросы, если VPN запрещает обход (Happ): запрос тихо идёт обычным путём
- ВКонтакте: вход больше не срывается из-за «flood control», понятные сообщения об ограничениях VK и повтор при «слишком много запросов»

## 0.2.0

- Тема **Liquid Glass**: настоящее стекло у бара и мини-плеера, пузырь-индикатор, переключатели-капли, живой фон
- 11 цветовых палитр
- Плеер сворачивается свайпом вниз, обложка в мини-плеере крутится как пластинка
- Свои иконки навигации
- OTA-обновления через GitHub Releases
- Исправлен белый экран при входе во ВКонтакте; можно вставить адрес страницы вместо токена
- Если VPN запрещает обход (Happ), Яндекс и ВК больше не падают с ошибкой, а идут через VPN

## 0.1.0

  свои плейлисты, перенос, офлайн, тексты, статистика, эквалайзер, таймер сна, профиль для Happ
